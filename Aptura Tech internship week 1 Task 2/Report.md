# 🎯 Number Guessing Game

## Aptura Tech Solution – Python Internship
### Week 1 – Task 2

---

## 1. Objective

The objective of this project is to develop a simple and interactive Number Guessing Game using Python and Streamlit.

---

## 2. Technologies Used

- Python
- Streamlit
- Random Module
- Object-Oriented Programming

---

## 3. Project Description

The game generates a random number between 1 and 100. The user enters guesses through the Streamlit interface.

The application provides hints such as **Too Low** or **Too High** until the correct number is guessed. It also tracks the number of attempts and provides a New Game option.

---

## 4. Features

- Random number generation
- User guessing system
- Too Low / Too High hints
- Correct guess notification
- Attempts counter
- New Game option
- Streamlit user interface
