# 🎯 Number Guessing Game

## Aptura Tech Solution – Python Internship
### Week 1 – Task 2

---

## 1. Objective

A simple interactive Number Guessing Game built using Python and Streamlit.

The user has to guess a randomly generated number between 1 and 100.

---

## 2. Technologies Used

- Python
- Streamlit
- Random Module
- Object-Oriented Programming

---

## 3. Features

- 🎲 Random number generation
- 🔢 Number range: 1–100
- ⬆️ Too Low / ⬇️ Too High hints
- 🎉 Correct guess notification
- 📊 Attempts counter
- 🔄 New Game option
- 🎨 Interactive Streamlit UI

---

## 4. How to Run

Install dependencies:

```bash
pip install -r requirements.txt
````

Run the application:

```bash
streamlit run app.py
```
