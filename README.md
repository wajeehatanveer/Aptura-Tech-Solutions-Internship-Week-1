# 🚀 Aptura Tech Solution – Week 1

## Python Internship – Batch 3

Week 1 of the Aptura Tech Solution Python Internship focuses on building practical Python applications with interactive Streamlit interfaces.

Two projects were completed during this week, covering student record management and game development.

---

## 📌 Projects

### 🎓 Task 1 – Student Record System

A Python and Streamlit-based application designed to manage student records efficiently.

**Key Features:**
- Add student records
- View all students
- Search students by ID
- Update student information
- Delete student records
- Dashboard with student statistics
- JSON-based data persistence
- Input validation

**Technologies:** Python, Streamlit, JSON, Object-Oriented Programming

---

### 🎯 Task 2 – Number Guessing Game

An interactive Number Guessing Game developed using Python and Streamlit.

The application generates a random number between 1 and 100 and provides hints to help the user find the correct number.

**Key Features:**
- Random number generation
- Too Low / Too High hints
- Correct guess notification
- Attempts counter
- New Game option
- Interactive Streamlit UI

**Technologies:** Python, Streamlit, Random Module, Object-Oriented Programming
